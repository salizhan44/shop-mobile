# shop-mobile

Мобильное приложение магазина (Expo). Каталог, корзина, заказы, поддержка.

API и база — в репозитории [shop-admin](https://github.com/salizhan44/shop-admin) (ветка `dev`). Сначала поднимите сайт и Postgres там.

## Требования

- Node.js 20+
- Expo Go на телефоне (iOS / Android)
- Запущенный `shop-admin` (`npm run dev` на http://localhost:3000)

## Первый запуск

```bash
npm install
cp .env.example .env
npm start
```

На **телефоне** приложение должно достучаться до API на компьютере:

- Телефон и ноутбук в одной Wi‑Fi сети.
- Запуск с LAN, например (PowerShell, подставьте IP ноутбука):

```powershell
$env:REACT_NATIVE_PACKAGER_HOSTNAME="192.168.1.10"
npx expo start --host lan
```

В `.env` при необходимости:

```
EXPO_PUBLIC_API_URL=http://192.168.1.10:3000
```

На эмуляторе / в браузере часто достаточно `http://localhost:3000` из `.env.example`.

## Вход в приложение (клиент)

Готового аккаунта **нет** — на экране **Регистрация**:

| Поле | Что вводить |
|------|-------------|
| Имя | любое, например `Тест` |
| Email | любой, например `client@local.test` |
| Пароль | **не короче 8 символов**, например `testpass8` |

У поля пароля есть кнопка **Показать / Скрыть**.

Уже есть аккаунт — **Вход** с тем же email и паролем.

**Не используйте** `owner@local.test` — это логин **сотрудника на сайте**, не клиента.

## Вход на сайт (для проверки заказов / поддержки)

См. [README shop-admin](https://github.com/salizhan44/shop-admin/blob/dev/README.md).

Кратко, после seed на сайте:

| Поле | Значение |
|------|----------|
| Email | `owner@local.test` |
| Пароль | `changeme` |

URL: http://localhost:3000

## Что есть в приложении

- Каталог, корзина, оформление заказа — цены в **сомах**
- **Мои заказы** — статусы от склада; кнопка **Обновить** и зелёная точка при новых изменениях
- **Поддержка** — обращения и ответы; так же **Обновить** и зелёная точка

Зелёная точка появляется, если склад или поддержка что-то изменили, пока экран открыт (проверка раз в ~30 сек).
